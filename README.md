# 📚 Personal Library Manager

A Personal Library Management System – Final Project for Programming Course

## ✨ Features

- 🔐 Login with username and password (MD5 hashed)
- 📖 Add, edit, delete, and search books
- 🔍 Advanced search by title, author, genre, status, and year range
- 📊 Statistical reports (total count, average rating, most frequent genre, percentage of read books)
- 💾 CSV storage with UTF-8 support
- 🖼️ Book cover image selection
- ⏰ Live date and time display

## 🛠 Technologies

- C# .NET 8
- Windows Forms
- CSV Storage
- MD5 Hashing
